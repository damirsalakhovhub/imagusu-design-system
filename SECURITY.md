# Security Policy

## Supported versions

Only the latest released minor version receives security fixes before 1.0.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories for this repository. Do not open a public issue. Include impact, reproduction steps, and affected versions when known.

RubyGems releases require maintainer MFA and GitHub OIDC Trusted Publishing. No long-lived RubyGems token is stored in the repository.
