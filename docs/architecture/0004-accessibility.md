# ADR 0004: Accessibility evidence

Status: accepted

## Decision

Target WCAG 2.2 AA within each component's documented assumptions. Use semantic HTML, rendered-output tests, automated accessibility checks when a browser workbench exists, and manual keyboard and assistive-technology scenarios before declaring a component stable.

## Consequences

No component is described as universally compliant outside its consuming page. Accessibility-relevant markup is a public contract.
